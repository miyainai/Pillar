---
name: Executive UX direction
description: User's design direction for Pillar's executive and operating-partner experience.
---

Keep Pillar simple to scan for PE deal leads and operating partners. Use concise
summaries, deliberate color, recognizable people, aligned comparisons, and
progressive disclosure rather than showing every available detail at once.
Retain useful operational detail and actions behind expansion, not by removing them.

**Why:** The user described the original platform as overwhelming and not intuitive,
and supplied a value-creation-plan reference as the direction for a more
executive-ready experience on 2026-10-24.

**How to apply:** Carry this direction into future plan and asks changes. Preserve
visibility boundaries when simplifying screens. On 2026-10-24 the user asked for
"fake profile photos", so the demo personas now use AI-generated portraits; keep
them consistent (one per persona, neutral headshot style) and never swap in real
people. The user also asked for copy that is "less AI-like": prefer plain,
specific sentences over generic product-speak, and explain what a figure means
in a few words next to it rather than in a tooltip. Interactions that change
state should ask for the specifics in a small form instead of acting silently.
